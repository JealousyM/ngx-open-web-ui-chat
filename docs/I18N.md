# Internationalization (i18n)

## Overview

The `openwebui-chat` component supports **10 languages** out of the box. Language can be changed dynamically at runtime.

## Supported Languages

| Language | Code | Native Name |
|----------|------|-------------|
| English | `en` | English |
| Chinese | `zh` | 中文 |
| Hindi | `hi` | हिन्दी |
| Spanish | `es` | Español |
| Arabic | `ar` | العربية |
| French | `fr` | Français |
| Portuguese | `pt` | Português |
| Russian | `ru` | Русский |
| Bengali | `bn` | বাংলা |
| Japanese | `ja` | 日本語 |

## Usage

### Basic Usage

```typescript
import { Component } from '@angular/core';
import { OpenwebuiChatComponent } from 'openwebui-embedded';

@Component({
  standalone: true,
  imports: [OpenwebuiChatComponent],
  template: `
    <openwebui-chat
      [endpoint]="endpoint"
      [modelId]="modelId"
      [apiKey]="apiKey"
      [language]="'ru'"
    ></openwebui-chat>
  `
})
export class AppComponent {
  endpoint = 'https://your-openwebui.com';
  modelId = 'llama3';
  apiKey = 'sk-your-key';
}
```

### Dynamic Language Switching

```typescript
import { Component, signal } from '@angular/core';
import { OpenwebuiChatComponent } from 'openwebui-embedded';

@Component({
  standalone: true,
  imports: [OpenwebuiChatComponent],
  template: `
    <div>
      <select [(ngModel)]="currentLanguage">
        <option value="en">English</option>
        <option value="ru">Русский</option>
        <option value="es">Español</option>
        <option value="zh">中文</option>
      </select>
      
      <openwebui-chat
        [endpoint]="endpoint"
        [modelId]="modelId"
        [apiKey]="apiKey"
        [language]="currentLanguage()"
      ></openwebui-chat>
    </div>
  `
})
export class AppComponent {
  currentLanguage = signal('en');
  endpoint = 'https://your-openwebui.com';
  modelId = 'llama3';
  apiKey = 'sk-your-key';
}
```

### Language Selector Component

```typescript
import { Component, signal } from '@angular/core';
import { OpenwebuiChatComponent } from 'openwebui-embedded';
import { CommonModule } from '@angular/common';

@Component({
  standalone: true,
  imports: [OpenwebuiChatComponent, CommonModule],
  template: `
    <div class="app-container">
      <div class="language-selector">
        <label>Language:</label>
        <select [value]="currentLanguage()" (change)="onLanguageChange($event)">
          @for (lang of languages; track lang.code) {
            <option [value]="lang.code">{{ lang.name }}</option>
          }
        </select>
      </div>
      
      <openwebui-chat
        [endpoint]="endpoint"
        [modelId]="modelId"
        [apiKey]="apiKey"
        [language]="currentLanguage()"
      ></openwebui-chat>
    </div>
  `
})
export class AppComponent {
  currentLanguage = signal('en');
  
  languages = [
    { code: 'en', name: 'English' },
    { code: 'zh', name: '中文 (Chinese)' },
    { code: 'hi', name: 'हिन्दी (Hindi)' },
    { code: 'es', name: 'Español (Spanish)' },
    { code: 'ar', name: 'العربية (Arabic)' },
    { code: 'fr', name: 'Français (French)' },
    { code: 'pt', name: 'Português (Portuguese)' },
    { code: 'ru', name: 'Русский (Russian)' },
    { code: 'bn', name: 'বাংলা (Bengali)' },
    { code: 'ja', name: '日本語 (Japanese)' }
  ];
  
  endpoint = 'https://your-openwebui.com';
  modelId = 'llama3';
  apiKey = 'sk-your-key';
  
  onLanguageChange(event: Event) {
    const select = event.target as HTMLSelectElement;
    this.currentLanguage.set(select.value);
  }
}
```

## Translated UI Elements

The following UI elements are translated:

### Button Text
- **Send button**: The text on the send button
  - EN: "Send"
  - RU: "Отправить"
  - ES: "Enviar"
  - etc.

### Input Placeholder
- **Message input**: Placeholder text in the message input field
  - EN: "Type your message..."
  - RU: "Введите ваше сообщение..."
  - ES: "Escribe tu mensaje..."
  - etc.

### Loading Indicator
- **Loading state**: Text shown during loading
  - EN: "Loading..."
  - RU: "Загрузка..."
  - ES: "Cargando..."
  - etc.

## Translation Object Structure

```typescript
interface Translation {
  send: string;           // Send button text
  placeholder: string;    // Input placeholder
  loading: string;        // Loading indicator text
}
```

## Custom Translations

If you need to add or modify translations, you can import and extend the translations object:

```typescript
import { translations } from 'openwebui-embedded';

// Access existing translations
console.log(translations['en'].send); // "Send"

// You can also use the getTranslation helper
import { getTranslation } from 'openwebui-embedded';

const translation = getTranslation('ru');
console.log(translation.send); // "Отправить"
```

## Fallback Behavior

If an unsupported language code is provided, the component will **automatically fallback to English** (`en`):

```typescript
<openwebui-chat [language]="'invalid-code'" ...></openwebui-chat>
// Will use English translations
```

## Performance

- Translations are **bundled with the library** - no external API calls
- Language switching is **instant** - uses Angular computed signals
- Zero performance impact - translations are small (< 1KB total)

## Contributing Translations

To add a new language:

1. Edit `projects/openwebui-embedded/src/lib/i18n/translations.ts`
2. Add a new entry to the `translations` object
3. Follow the existing structure
4. Submit a pull request

Example:
```typescript
export const translations: Translations = {
  // ... existing translations
  de: {  // German
    send: 'Senden',
    placeholder: 'Geben Sie Ihre Nachricht ein...',
    loading: 'Laden...'
  }
};
```

## Troubleshooting

### Language Not Changing

**Problem:** Language doesn't update when changed

**Solution:** Ensure you're using a signal or triggering change detection:
```typescript
// Good - uses signal
currentLanguage = signal('en');

// Update
this.currentLanguage.set('ru');
```

### Missing Characters

**Problem:** Special characters don't display correctly

**Solution:** Ensure your HTML file includes UTF-8 charset:
```html
<meta charset="UTF-8">
```

### RTL Layout Issues

**Problem:** Arabic text layout is incorrect

**Solution:** The component handles RTL automatically, but ensure your app's CSS doesn't override text direction.
